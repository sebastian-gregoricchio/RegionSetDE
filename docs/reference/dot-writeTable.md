# .writeTable

Writes a table as a tab separated file, gzipped when asked for.

## Usage

``` r
.writeTable(table, path, compress = TRUE)
```

## Arguments

- table:

  Data.frame to write.

- path:

  String with the destination.

- compress:

  Logical value indicating whether the file must be gzipped.

## Value

Invisibly the path.
