# .checkPlotRegionArguments

Checks the arguments of
[`plotRegion`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/plotRegion.md)
and brings them to the form the rest of the function works with.

## Usage

``` r
.checkPlotRegionArguments(
  object,
  counts,
  contrast,
  groupBy,
  summarise,
  pairwiseTest,
  pairBy,
  comparisons,
  pAdjustMethod,
  pLabel,
  pDecimals
)
```
