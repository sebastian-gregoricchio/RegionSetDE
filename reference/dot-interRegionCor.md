# .interRegionCor

Estimates the correlation between the regions of a set, from the
residuals of the design.

## Usage

``` r
.interRegionCor(expressionMatrix, design, index)
```

## Arguments

- expressionMatrix:

  Numeric matrix of log2 values.

- design:

  Design matrix.

- index:

  Integer vector with the rows of the set.

## Value

A numeric value.
