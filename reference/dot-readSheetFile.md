# .readSheetFile

Reads a sample sheet from a comma or tab separated file, the separator
being taken from the extension or, failing that, from the first line.

## Usage

``` r
.readSheetFile(path)
```

## Arguments

- path:

  String with the path to the file.

## Value

A data.frame, with the column names as written in the file.
