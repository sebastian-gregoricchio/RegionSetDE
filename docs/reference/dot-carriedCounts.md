# .carriedCounts

Returns the counts carried by a results object, and stops when the test
left them behind.

## Usage

``` r
.carriedCounts(results)
```

## Arguments

- results:

  `RegionSetDE.results`, `RegionSetDE.setResults` or either of the two
  list classes.

## Value

A `RegionSetDE.counts` object.
