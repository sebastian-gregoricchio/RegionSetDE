# .upsetGroupColours

Gives one colour per group, from the user when given and from the
palette of the package otherwise.

## Usage

``` r
.upsetGroupColours(groupLevels, groupColours = NULL)
```

## Arguments

- groupLevels:

  Character vector with the groups, ordered.

- groupColours:

  Character vector with the colours of the user, named or in the order
  of the groups, or `NULL`.

## Value

A named character vector with one colour per group.
