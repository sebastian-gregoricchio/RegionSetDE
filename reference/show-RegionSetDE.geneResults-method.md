# show method for RegionSetDE.geneResults

Prints a summary of a per-gene table: the contrast it came from, how it
was aggregated and weighted, how many genes and links it holds, how the
genes split between the four directions, and the first rows of the
table.

## Usage

``` r
# S4 method for class 'RegionSetDE.geneResults'
show(object)
```

## Arguments

- object:

  `RegionSetDE.geneResults` object.

## Value

Prints the summary to the console.
