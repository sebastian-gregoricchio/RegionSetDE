# .replaceCounts

Writes a counts object back where it came from, the counterpart of
[`.countsOfObject`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/dot-countsOfObject.md).

## Usage

``` r
.replaceCounts(object, counts)
```

## Arguments

- object:

  Object the counts were taken from.

- counts:

  `RegionSetDE.counts` object to store.

## Value

The input object carrying the new counts.
