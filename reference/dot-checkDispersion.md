# .checkDispersion

Validates a dispersion given by the user.

## Usage

``` r
.checkDispersion(dispersion, source = "supplied", engine = "edgeR")
```

## Arguments

- dispersion:

  Numeric value.

- source:

  String with where it came from.

- engine:

  String with the engine being used.

## Value

A list with the `dispersion`, its `source` and an empty holdout.
