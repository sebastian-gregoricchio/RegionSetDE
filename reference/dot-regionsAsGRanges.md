# .regionsAsGRanges

Pools the regions of a `RegionSetDE` object, a `GRangesList` or a list
of `GRanges` into a single `GRanges`, without metadata.

## Usage

``` r
.regionsAsGRanges(regions)
```

## Arguments

- regions:

  A `RegionSetDE` object, a `GRangesList`, a list of `GRanges` or a
  `GRanges`.

## Value

A `GRanges`.
