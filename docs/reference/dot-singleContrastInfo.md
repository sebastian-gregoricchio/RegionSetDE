# .singleContrastInfo

Builds the row of
[`contrastInfo`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/contrastInfo.md)
for one contrast.

## Usage

``` r
.singleContrastInfo(results, contrastKey)
```

## Arguments

- results:

  `RegionSetDE.results` object.

- contrastKey:

  String with the name the contrast goes under.

## Value

A data.frame with one row.
