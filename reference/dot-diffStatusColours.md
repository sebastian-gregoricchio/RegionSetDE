# .diffStatusColours

Returns the palette of the `diff.status` column, completed with the
defaults when only part of it is given.

## Usage

``` r
.diffStatusColours(colours = NULL)
```

## Arguments

- colours:

  Named character vector, or `NULL`.

## Value

A named character vector with the `down`, `null` and `up` entries.
