# .defaultAssay

Picks the assay a plot should draw, preferring the normalised values
when the object holds them.

## Usage

``` r
.defaultAssay(counts, assay = NULL)
```

## Arguments

- counts:

  `RegionSetDE.counts` object.

- assay:

  String with the name of an assay, or `NULL`.

## Value

A string with the name of the assay.
