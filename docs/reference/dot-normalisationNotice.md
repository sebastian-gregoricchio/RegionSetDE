# .normalisationNotice

Says when the normalised values were asked for but the object carries no
normalisation, in which case the library sizes are used.

## Usage

``` r
.normalisationNotice(counts, useOffsets = TRUE, verbose = TRUE)
```

## Arguments

- counts:

  `RegionSetDE.counts` object.

- useOffsets:

  Logical value indicating whether the normalised values were asked for.

- verbose:

  Logical value to indicate whether the message must be printed.

## Value

Nothing, it prints a message at most.
