# .resultColumnNames

Lists the column names
[`testRegions`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegions.md)
writes itself, so that a column carried by the regions can be spotted
before it overwrites one of them.

## Usage

``` r
.resultColumnNames()
```

## Value

A character vector.
