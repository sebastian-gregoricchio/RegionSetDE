# .lightenColour

Mixes a colour with white, used to build the light end of the shades of
a group.

## Usage

``` r
.lightenColour(colour, amount = 0.5)
```

## Arguments

- colour:

  String with the colour.

- amount:

  Numeric value between 0 and 1 with the fraction of white.

## Value

A string with the mixed colour.
