# .checkFitRegionsArguments

Checks the arguments of
[`fitRegions`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/fitRegions.md)
and brings them to the form the rest of the function works with.

## Usage

``` r
.checkFitRegionsArguments(counts, engine, block, random, assay)
```

## Arguments

- counts:

  See
  [`fitRegions`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/fitRegions.md).

- engine:

  See
  [`fitRegions`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/fitRegions.md).

- block:

  See
  [`fitRegions`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/fitRegions.md).

- random:

  See
  [`fitRegions`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/fitRegions.md).

- assay:

  See
  [`fitRegions`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/fitRegions.md).

## Value

A list with the arguments as checked and completed: `engine`.
