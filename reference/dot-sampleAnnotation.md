# .sampleAnnotation

Returns the `colData` of a counts object as a data.frame, with the
sample names in a first `sample` column.

## Usage

``` r
.sampleAnnotation(counts)
```

## Arguments

- counts:

  `RegionSetDE.counts` object.

## Value

A data.frame with one row per sample, in the order of the object.
