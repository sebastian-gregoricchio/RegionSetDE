# .checkScoreRegionSetsArguments

Checks the arguments of
[`scoreRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/scoreRegionSets.md)
and brings them to the form the rest of the function works with.

## Usage

``` r
.checkScoreRegionSetsArguments(counts, reference, assay, summary, confLevel)
```

## Arguments

- counts:

  See
  [`scoreRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/scoreRegionSets.md).

- reference:

  See
  [`scoreRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/scoreRegionSets.md).

- assay:

  See
  [`scoreRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/scoreRegionSets.md).

- summary:

  See
  [`scoreRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/scoreRegionSets.md).

- confLevel:

  See
  [`scoreRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/scoreRegionSets.md).

## Value

A list with the arguments as checked and completed: `assay`,
`backgroundCounts`.
