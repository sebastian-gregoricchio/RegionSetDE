# .universeDiagnostics

Summarises how close the comparison rows of a universe sit to the set
they were drawn for.

## Usage

``` r
.universeDiagnostics(rowTable, universeIndex, setNames)
```

## Arguments

- rowTable:

  Data.frame with the row level covariates.

- universeIndex:

  List with the universe positions of every set.

- setNames:

  Character vector with the names of the sets.

## Value

A data.frame with one row per set.
