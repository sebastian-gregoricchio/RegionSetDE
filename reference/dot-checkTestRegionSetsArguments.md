# .checkTestRegionSetsArguments

Checks the arguments of
[`testRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegionSets.md)
and brings them to the form the rest of the function works with.

## Usage

``` r
.checkTestRegionSetsArguments(
  fit,
  effectMethod,
  tileHandling,
  overlapPolicy,
  overlapWithinSet,
  fryInput
)
```

## Arguments

- fit:

  See
  [`testRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegionSets.md).

- effectMethod:

  See
  [`testRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegionSets.md).

- tileHandling:

  See
  [`testRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegionSets.md).

- overlapPolicy:

  See
  [`testRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegionSets.md).

- overlapWithinSet:

  See
  [`testRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegionSets.md).

- fryInput:

  See
  [`testRegionSets`](https://sebastian-gregoricchio.github.io/RegionSetDE/reference/testRegionSets.md).

## Value

A list with the arguments as checked and completed: `effectMethod`,
`fryInput`, `overlapPolicy`, `overlapWithinSet`, `tileHandling`.
